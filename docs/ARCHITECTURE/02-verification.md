# Weryfikacja

| Cel | Komenda | Znaczenie |
| --- | --- | --- |
| build | `make build` | Sprawdza skladnie serwera aplikacji. |
| test | `make test` | Uruchamia test pionowej sciezki. |
| smoke | `make smoke` | Test pionowej sciezki w Chromium. |
| ci | `make ci` | Aktualny zestaw kontroli CI, obecnie smoke. |
| hardware | `make hardware` | Potwierdza dostepnosc Chromium. |
